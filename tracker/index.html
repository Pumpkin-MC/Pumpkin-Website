How this list is kept honest

Every entry is checked against the Pumpkin source: an entity counts as implemented when it has its own type with a goal set that matches vanilla, partial when the type exists but goals or mechanics are missing, and missing when nothing maps to it yet. The checklists come from the maintainers' tracking issues and from reading the code.

Spotted a mistake or shipped something new? Edit tracker/data.json and open a pull request.
